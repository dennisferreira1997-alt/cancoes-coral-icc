# 🎵 Canções do coral — ICC São Carlos

Página para buscar uma canção do coral e abrir direto no trecho do culto em que ela foi cantada.

- `app.py` — app Streamlit (busca, "Abrir no YouTube", "Ouvir aqui")
- `resultados.csv` — gerado pelo `buscar_musicas.py` (lista de canções × cultos × minutos)

**Atualizar:** rode o `buscar_musicas.py` no computador e envie o novo
`resultado_busca/resultados.csv` para cá (Add file → Upload files). O app atualiza sozinho.
